# Bob Idle v1 — ручная проверка

Эти сценарии ещё не пройдены на Android в рабочей среде. SVG-предпросмотры проверены отдельно; это не заменяет запуск приложения. Использовать тестовое устройство/эмулятор и тестовые данные.

## Подготовка

```powershell
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug
```

Установить полученный debug APK. Для сценария C нужна чистая тестовая установка: установка поверх существующей сохраняет onboarding state. Удаление данных затрагивает привычки и настройки, поэтому не выполнять его на единственной копии пользовательских данных.

## A — вкладка Боба и Home

- [ ] Открыть вкладку Bob и наблюдать 15–20 секунд.
- [ ] Боб мягко поднимается/опускается, полный цикл около 2.8 с; корпус не перемещается по X.
- [ ] Четыре части нижнего края слегка колышутся с разной фазой, без ходьбы и отрыва от тела.
- [ ] Свободный конец зелёного шарфа слегка качается; шарф на шее прикреплён.
- [ ] Волосы и руки сохраняют форму и места крепления.
- [ ] Глаза моргают; рот остаётся неподвижным.
- [ ] Повторить на Home и на компактной/альбомной компоновке Mascot Screen.
- [ ] Проверить, что Боб помещается в прежние размеры, не обрезается и не вызывает скачков layout.

## B — моргание и жизненный цикл

- [ ] Между морганиями примерно 2 секунды; полное моргание около 0.3 с.
- [ ] Видна последовательность OPEN → HALF → CLOSED → HALF → OPEN.
- [ ] HALF — отдельная форма века, а не сплющенный глаз.
- [ ] После моргания положение, размер и блики глаз совпадают с исходными.
- [ ] Парение, шарф и нижний край продолжают двигаться во время моргания.
- [ ] Перейти на экран без Боба, свернуть приложение, затем вернуться: нет зависшего лица, ошибок или лишней работы после удаления компонента.
- [ ] Проверить системный масштаб анимаций 0 и обычный масштаб; восстановить исходную настройку устройства.

## C — первое приветствие

- [ ] На чистой тестовой установке дождаться окончания неизменённой Startup Animation.
- [ ] На WELCOME работает idle и меняются несколько форм рта с неодинаковыми интервалами.
- [ ] Нажать прежнюю кнопку «Продолжить»; следующий HOME step работает как раньше.
- [ ] На HOME и следующих обычных coach steps рот больше не разговаривает.
- [ ] Проверить Settings confirmation: idle работает, talking не включён.
- [ ] Позиционирование WELCOME не оценивать как результат этой задачи: layout сохранён из текущего проекта.

## D — Blocking / Praise / подтверждение привычки

- [ ] Вызвать Blocking штатным способом либо существующей debug-командой тестового overlay.
- [ ] Боб сохраняет грустное/блокирующее выражение, не улыбается во время речи.
- [ ] Работают мягкое парение, нижняя волна, шарф, моргание и talking.
- [ ] Кнопки и логика блокировки работают как прежде; scrim остаётся 0.85.
- [ ] Закрытие overlay не оставляет анимацию/ошибки в фоне.
- [ ] В Praise радостное выражение сохраняется, есть idle и моргание, нет talking.
- [ ] В подтверждении привычки Боб анимирован, но не разговаривает; подтверждение/отказ работают как прежде.

## E — Launcher

- [ ] Обычная и круглая launcher icons не изменились и остаются статичными.
- [ ] Монохромный значок вкладки Bob остаётся прежним навигационным символом.

## F — Startup

- [ ] Системный splash, изображение, поворот и длительности StartupHost не изменились.
- [ ] Новый BobMascot не рисуется вместо startup asset.

## G — Debug preview

- [ ] Settings → Developer → Debug → Bob Animation Preview.
- [ ] Переключить Idle, Blocking и Happy; форма персонажа и выражения корректны.
- [ ] Talking ON: несколько форм, разные интервалы. OFF: немедленный возврат к неподвижному рту соответствующего выражения.
- [ ] «Моргнуть сейчас»: один цикл, плавное движение тела не перезапускается.
- [ ] «Границы слоёв и pivots»: видны тело, волосы, шарф, руки, четыре части низа, глаза и рот.
- [ ] В release build этот preview не показывается.

## H — производительность и размеры

- [ ] Проверить 72, 140, 180, 192, 224 и 240 dp, а также увеличенный системный размер шрифта.
- [ ] Наблюдать несколько минут и повторить открытие/закрытие overlay: нет нарастающих задержек или исключений.
- [ ] На реальном устройстве проверить frame timing/Profile GPU rendering. Цель — 60 FPS; в отчёте не выдавать целевую величину за измеренную.
