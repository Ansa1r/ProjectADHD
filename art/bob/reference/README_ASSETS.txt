ProjectADHD Alpha - Bob Idle Vector Animation assets

source_parts/
- Original Bob raster parts supplied by the user. These are reference/source materials, not final animation frames.
- Preserve Bob's proportions, colors, face placement and overall silhouette.

references/ghost_lower_body_motion_reference.gif
- Motion reference ONLY for the soft wave/deformation of the ghost's lower edge.
- Do NOT copy the side-to-side walking/movement from the reference.

references/scarf_motion_reference.png
- Motion/style reference ONLY for a subtle scarf tail sway, as if moved by a very light breeze.
- Bob's own green scarf design must remain unchanged.

references/face_expression_reference.png
- Reference sheet for additional eye, mouth and eyebrow states.
- The final vectors should preserve the original Bob art style rather than copying any accidental differences in this generated sheet.

references/bob_layer_separation_reference.png
- Conceptual guide for splitting body, green hair, scarf, arms and lower ghost lobes into separate vector layers.
- It is a guide, not a replacement design.

references/bob_composite_reference.png
- Reconstructed Bob from supplied parts for placement/alignment reference.

IMPORTANT
- Final implementation must be real vector animation (SVG / Android vector paths / Compose vector layers), NOT a GIF, WebP animation, sprite sheet, or 60 raster PNG frames.
- Raster files in this archive are references to be traced/rebuilt into vector paths.
